# 혜택 캘린더

카드와 멤버십 혜택을 **월별로 한눈에** 보고, 사용 여부와 아낀 금액을 기록하는 개인용 웹앱(PWA)입니다.
서버 없이 동작하고, 데이터는 기기의 브라우저(localStorage)에만 저장됩니다.

## 기능
- **이번 달**: 아낀 금액, 혜택 사용 현황, 이번 달 소멸 예정 혜택, 연회비 회수율
- **카드 실적**: 이번 달 이용금액을 입력하면 실적 구간 진행 바가 나오고, 다음 구간까지 남은 금액을 알려줍니다. 전월 실적 기준으로 혜택 충족/미달과 구간별 한도를 자동 계산합니다.
- **혜택 주기**: 매월 / 분기 / 연간 / 상시. 횟수 한도, 금액 한도, 실적 구간별 한도를 지원합니다.
- **기록**: 최근 6개월 아낀 금액 그래프, 연회비 대비 누적, 월별 사용 내역
- **관리**: 카드·멤버십·혜택 추가/편집, JSON 백업 내보내기/가져오기
- 오프라인 동작, 다크 모드, 홈 화면 추가 지원

## 휴대폰/아이패드에서 쓰기
1. GitHub 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
2. `main`(또는 `master`) 브랜치에 푸시하면 `.github/workflows/pages.yml` 이 자동 배포
3. Safari에서 `https://<아이디>.github.io/<저장소명>/` 접속 → 공유 버튼 → **홈 화면에 추가**

> 휴대폰과 아이패드의 데이터는 따로 저장됩니다. 옮기려면 관리 탭의 **내보내기 → 가져오기**를 쓰세요.

## 로컬 실행
```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 |
| `data.js` | 처음 실행할 때 쓰는 예시 데이터 (카드 3종, 멤버십 4종) |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA (오프라인, 홈 화면 아이콘) |
| `gen-icons.cjs` | 아이콘 PNG 재생성 스크립트 |

## 예시 데이터 주의
`data.js` 의 카드 혜택은 2026년 기사와 카드 비교 사이트를 참고한 **예시**입니다. 연회비와 세부 조건은 각 카드사·멤버십 앱에서 확인한 뒤 앱의 **관리** 탭에서 수정하세요.
